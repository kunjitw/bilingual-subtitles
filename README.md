# Bilingual Subtitles

幫 YouTube 影片產生字幕、翻成中文，播放時雙語字幕一起顯示。拿來學日文和英文，全部在你自己的電腦上跑。

## 你需要

- Windows 10 或 11
- NVIDIA 顯示卡，顯存 8GB 以上
- 顯示卡驅動 580 版以上
- 硬碟空間 30GB 以上

## 安裝（只做一次）

1. 在 zip 上按右鍵 →「內容」→ 勾「解除封鎖」→ 確定。
2. 解壓縮到 `D:\BilingualSubtitles` 這種地方。
   - 路徑只能有英文和數字，不能有中文。
   - 不要放在 OneDrive 或 Program Files 裡。
3. 雙擊 `start.bat`，等它跑完。
   - 會下載約 2.5GB，實測約 3 分鐘，網路慢會久一點。
   - 中途關掉沒關係，再開會接著下載。
4. 瀏覽器自己打開，就是裝好了。

## 模型和字典

第一次打開會自動裝好需要的模型和字典，最多約 14GB，實測約 4 分鐘。畫面會顯示進度，可以先去用，裝好的部分就能先用。

## 每天用

| 想做 | 怎麼做 |
|---|---|
| 開 | 雙擊 `start.bat` |
| 關 | 關掉黑色視窗 |
| 加影片 | 上方「新增影片」→ 貼網址 → 選影片語言 →「加入佇列」 |
| 看進度 | 右邊「佇列」分頁 |
| 看影片 | 左邊播放列表點影片 |

## 看影片時

| 想做 | 怎麼做 |
|---|---|
| 查單字 | 滑鼠停在字幕的字上（手機用點的） |
| 改字幕大小、位置 | 影片下方「字幕外觀」 |
| 看快捷鍵 | 按 `?` |
| 複習單字 | 上方「單字」 |

## 用手機看

1. 電腦：「設定」→ 打開「讓同一個網路的手機、平板連線」。
2. 關掉 `start.bat` 再重開。
3. 手機連同一個 Wi-Fi，打開設定頁上寫的網址。

在咖啡廳這種公共網路，把開關關掉。

## 要玩遊戲

在「佇列」分頁或「設定」的顯示卡區按「釋放顯卡」。沒任務時，2 分鐘後也會自己釋放。

佇列還有任務時會先問，確認後佇列暫停；玩完按「繼續佇列」，從中斷的地方接著做。

## 出問題

| 狀況 | 怎麼辦 |
|---|---|
| `start.bat` 說路徑不行 | 照畫面說的，把資料夾搬到別的地方 |
| YouTube 說 Sign in to confirm you're not a bot | 「設定」→「下載影片」→ 瀏覽器 cookies 選你有登入 YouTube 的瀏覽器 |
| 開不起來、壞掉 | 雙擊 `repair.bat` |
| 其他 | 把 `data\app.log` 傳給我 |

## 移除

刪掉整個資料夾就好，不會在電腦裡留東西。
